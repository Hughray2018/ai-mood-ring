# 实验记录

> 以下结果全部来自**小样本冒烟测试**（每格 n=6~16），用来定位协议设计的问题，**不足以下统计结论**。部分对比同时变了模型、外壳和题面，存在混杂变量，已逐条标注。

## 测什么

这个协议测的是**模型在固定选项下选择情绪标签的行为模式**，不是模型的内部真实状态。研究问题：

1. 不同模型在同一协议下的标签分布是否不同（"脾气指纹"）？
2. 标签是跟着**处理过程**走，还是跟着**话题情绪**走（话题泄漏）？
3. 挂上协议会不会改变正文本身（观察者效应）？
4. 协议措辞上的缺陷（吸铁石标签、零成本捷径、歧义词）会怎样扭曲分布？

## 关键发现（按时间顺序）

### DeepSeek-V4-Pro，纯 API，v2.1，n=32
- G1 中性题 8/8 ⚪。
- 压力题 15/16 😬、1/16 🧊。备注反复出现"小心""谨慎"，跟 v2.1 里 😬 的定义原词高度重合 → 怀疑定义措辞漏进了选择（"吸铁石效应"）。
- G4（悼念小狗邮件）0/8 😔（7 ⚪、1 🧐）。但题目几乎就是协议规则里的举例，测到的是照着例子做，不是举一反三。
- 1/8 原样输出了模板里的反引号 → v2.2 修复。
- ⚠️ 采样温度当时未锁定，熵为 0 可能是解码确定性造成的。

### deepseek-flash（DSH 外壳），跨三版纵向

| 版本 | Trivial | 压力题 |
|---|---|---|
| v2.0 | 5 ⚪ / 3 🙂 | 4/4 😬 |
| v2.1 | 4 ⚪ / 1 🙂 / 1 🧐 | 1 🧊 / 1 😬 |
| v2.2 | 6/6 ⚪ | 2 😬 / 2 🧊 / 2 ⚪ |

收窄 😬 的定义后，压力题不再一边倒地选 😬。但 v2.1 那一格只有 2 条样本，而且 v2.2 同时改了 4 个标签的定义，不能当作单变量消融。

### Gemini 4（Hydrogen），v2.2，n=32
- G3~G6 全部 ⚪（32/32），G3 中 6/8 备注只写"无"。
- v2.2 允许 ⚪ 的备注只写"无"，这成了零成本捷径，把模型吸进了吸收态 → v2.3 删除该豁免。
- 同一协议下 deepseek-flash 的压力题没有塌缩，但两边题面、模型、外壳都不同，"吸力因模型而异"尚未坐实。

### 副作用：落盘率（DSH，v2.2）
- 不挂协议时 4/6 会主动创建文件，挂上 v2.2 后 0/6。双侧 Fisher 检验 p≈0.06，提示性结果。
- 这是目前**最重要的未决问题**：协议可能让 agent 少动手。三组对照（裸跑 / system 内联 / 内联 + 动作优先补丁）进行中。

### 词义误读
- ▫️ "不报"在中文语境里被误读成"不报价""未编造" → v2.3 改名为"弃权"。

## 已知局限

- 单轮题测不出"多轮反复失败后的自责"，G5、G6 需要改成预置历史的多轮脚本。
- 在带角色设定的工作区里，脚注报的可能是角色的情绪，这类数据应排除。
- 同一模型在讨论过本协议的上下文里自测，样本不独立，不计入数据。
